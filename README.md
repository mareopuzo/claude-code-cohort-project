# Claude Code Cohort Project

Full go to market and outbound engine, built strategy first with Claude Code as the cohort project by Mario Okhiria.

**Offer:** a free QA audit on a prospect staging environment. Surface the critical bugs, hook the buyer, then upsell the paid backend QA.
**ICP:** B2B healthcare SaaS in the USA.

## What is here

| File | What it is |
|------|------------|
| `strategy.md` | The strategy doc. The brain of the system, written before any tool was opened. |
| `diagram.html` | Interactive workflow diagram (Mermaid, pan and zoom). Open in a browser. |
| `workflow.mmd` | The Mermaid source for the diagram. |
| `workflow.excalidraw` | The same flow as an Excalidraw canvas. Import at excalidraw.com. |
| `landing/` | The animated landing page for this project. Deployed on Vercel. |
| `.env.example` | Template for the AI Ark key. Copy to `.env` (git ignored). |
| `data/` `logs/` `copy/` | Working folders for lists, run logs and copy. |
| `gtm-systems-thinking-agent/` | The upstream planning agent that produces the strategy before the build. |

## The system in one line

Strategy, then list build with AI Ark, then segment by size and subvertical, then run two engines at once. A volume engine of founder led copy plus spintax, and a signal engine personalized one to one with Clay and Claygent. Domains warm for 21 days, a human approves every send, PlusVibe sends, every run lands in logs, and the weekly review loops back to strategy.

## Stack

AI Ark, Clay, Claygent, Claude Code, ScaledMail, PlusVibe, Excalidraw, Mermaid.

Built with Claude Code.
